# CereniaDLC — UI refresh

## Что изменено
- Тёмная графитово-сине-фиолетовая палитра.
- Псевдо-скруглённые панели и карточки, нарисованные обычным GUI renderer.
- Лёгкие движущиеся фоновые частицы и пульсация акцента.
- Мини-иконки модулей, включая пиксельный меч для боевых модулей.
- Сохранена существующая структура проекта и настройки Fabric.

## Важно
Это обновление интерфейса, а не новый графический движок. Файлы GLSL сами по себе не активируют шейдеры: для настоящего shader pipeline нужна отдельная регистрация под API Minecraft 26.2. В исходном проекте только Sprint, Fullbright и ClickGUI зарегистрированы как модули; остальные функции нельзя считать реализованными, пока не написан их игровой код. Сборку нужно проверить локально командой `./gradlew build`.
